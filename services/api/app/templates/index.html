Transverse-field SK problem

Provide the dense coupling matrix J together with optional longitudinal (h) and transverse (g) fields as .npy files. The solver minimises the transverse-field Sherrington–Kirkpatrick Hamiltonian:

H = ∑ij Jij σiz σjz + ∑i hi σiz − ∑i gi σix

Leave optional vectors and uniform value fields blank for zero fields. Do not supply the longitudinal field inputs when using the QUBO box below.

QUBO problem

Submit a QUBO matrix Q (.npy). The solver minimises the quadratic form below and automatically converts the problem to the equivalent Ising J and h. Do not upload the same instance in both boxes.

f(x) = ∑i,j Qij xi xj,   xi ∈ {0, +1}

The annealer works in the Ising basis, so returned spin assignments are in {−1, +1}; map them back to binary with xi = (1 + σi)/2 if needed.

Only one of the boxes above should be populated for each submission.
